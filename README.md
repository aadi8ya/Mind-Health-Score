# 🧠 Mental Health Score Predictor

[🚀 Live Demo Link](https://mind-health-score-1.onrender.com)

An end-to-end **Machine Learning web application** that predicts a student's **Mental Health Score** based on lifestyle, academic, digital usage, and stress-related factors.

## 🚀 Features

* Exploratory Data Analysis & Data Preprocessing
* Regression-based Machine Learning
* Random Forest Regressor
* Hyperparameter Tuning using RandomizedSearchCV
* Model Evaluation using **R², RMSE & MAE**
* REST API using **FastAPI**
* Data Validation using **Pydantic**
* Interactive frontend using **HTML, CSS & JavaScript**
* Integrated ML prediction pipeline

## 🛠️ Tech Stack

**Machine Learning:** Python, Pandas, NumPy, Scikit-learn, Joblib
**Backend:** FastAPI, Pydantic, Uvicorn
**Frontend:** HTML, CSS, JavaScript
**Visualization:** Matplotlib, Seaborn

## 🔄 Project Workflow

```text
User Input
    ↓
HTML / CSS / JavaScript
    ↓
FastAPI API
    ↓
Pydantic Validation
    ↓
ML Preprocessing Pipeline
    ↓
Random Forest Model
    ↓
Mental Health Score
    ↓
JSON Response → Frontend
```

## 📊 Machine Learning

**Problem Type:** Regression
**Target Variable:** `Mental_Health_Score`
**Final Model:** Random Forest Regressor

The model uses academic, lifestyle, social-media usage, sleep, physical activity, and stress-related features to estimate the Mental Health Score.

## ⚠️ Disclaimer

This project is developed for **educational purposes only**. Predictions should not be considered a professional medical or psychological assessment.
